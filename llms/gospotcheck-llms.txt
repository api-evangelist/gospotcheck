# GoSpotCheck (by FORM) External API

> GoSpotCheck by FORM is a mobile field-execution and retail-execution platform. Its External API lets you sync people, places, place groups, teams, catalogs, and catalog items, and pull mission (survey/task) response data out of GoSpotCheck to build custom reports and integrations. REST over HTTPS, OAuth2 bearer auth, a standard response envelope (request/paging/data/errors), page-number pagination, field-operator filtering, and asynchronous CSV export for large datasets.
